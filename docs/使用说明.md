# 到期台账 使用说明

## 谁该用

- 手上有一堆合同、证照，怕哪天忘了续期的行政、法务、门店负责人
- 要定期盘点「这个月什么到期」的管理者

## 三步上手

1. **导入**：点列表页右上角的「导入」，上传合同或证照文件，或者把文字整段粘进来
2. **确认**：AI 把内容抽成一条条的，每条都能改、能删、能取消勾选。缺到期日的会标出来，确认后才入库
3. **跟进**：列表上一眼看到还剩几天，到期前按你设的时间收到提醒

不想用 AI 也可以：点「新建」一条条填，或在导入页点「不经过 AI，按行批量录入」，每行写「名称, 到期日, 类别」。

## 导入支持与限制

| 来源 | 要求 | 说明 |
|---|---|---|
| 粘贴文字 | 最多 5 万字 | 合同关键信息、证照信息、一整张台账表都行 |
| PDF `.pdf` | 单个 ≤10MB | 要带文字层，只读前 60 页。扫描件读不了，请粘贴文字 |
| Word `.docx` | 单个 ≤10MB | 读正文和表格；老版 `.doc` 请先另存为 `.docx` |
| 文本 `.txt` `.md` | 单个 ≤10MB | UTF-8 或 GBK 编码都可以 |
| 图片 `.png` `.jpg` | 暂未开通 | 图片识别暂未开通，请先把证件信息转成文字 |

一次最多传 5 个文件，每份最多识别 20 条。上传的文件只用来识别，不会保存；要留存原件，到条目里传附件。

确认页上的标记：

- **缺到期日**：文件里没写，或者写的是长期有效。可以先导入，但补上日期之前不会提醒。统计行末尾的「只看缺到期日」能把它们筛出来
- **日期是推算的，请核对**：这个日期在原文里找不到，多半是按起始日和期限算出来的，导入前看一眼

## 分类怎么维护

点右上角头像 →「设置」→「分类」：

- **添加**：最多 8 个字，新分类排在「其他」前面
- **改名**：这个分类下你的条目跟着改
- **删除**：其下的条目转到「其他」，条目本身不删
- **排序**：点 ↑ ↓，列表上方的分类筛选和 AI 的可选项都跟着变

「其他」是兜底分类，不能改名和删除。AI 只能从清单里选，选不出来就归到「其他」。

分类每人一份。v0.1 用的「合同」「证照」等老分类，只要还有条目在用就留在清单里，可以改名或删除。

## 提醒怎么配

点头像 →「设置」：

- **提醒时间**：每天几点推送，按整点选
- **默认提醒天数**：新建和导入时没写提前多少天，就用这个。每条也能单独改
- **默认负责人**：新建和导入时没写负责人，就指给这个人。对方能看到条目，也由对方收提醒
- **平台通知**：往钉钉、飞书、企业微信发一条汇总。一人一天一条，同一条目同一档位一天只提醒一次

提醒发给负责人，没指定负责人的发给创建人。提醒时间按收提醒的人自己的设置算。

## 视图和导出

- **时间**：点「已过期」「今天到期」「7 天内」「30 天内」筛选，再点一次取消
- **日历**：切到「日历」按月看，有到期项的日子能点，点某天筛出当天条目。缺日期的列在下面
- **导出**：点「导出」选范围（当前筛选 / 全部）和格式。CSV 用 Excel 打开中文不乱码

## 常见问题

**提示「自动识别失败，可以手动录入」？**
模型这次没有返回可用结果。点「手动新增」一条条填，或用「批量录入」，也可以稍后再试。

**提示「这是扫描件」？**
PDF 里只有图片没有文字层，目前读不了。用 Word 或 WPS 转成文字后再导入，或者把文字粘贴进来。

**文件里写的负责人能看到条目吗？**
不能。文件里的姓名只记成文字。能看到条目的只有创建人和在系统里选的负责人，提醒也不会发给文件里写的人。要让对方收到，打开条目选择平台上的负责人。

**同一份文件导入两次会怎样？**
会有两份，目前不查重。导入前留意一下，多出来的打开条目删除。

**设置改了要重启吗？**
不用，下一次操作就生效。设置只影响你自己。
